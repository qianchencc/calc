# 按真实阶梯分组直接统计

2026-09-07，站点所有者确认只需要粗略经验估算：各阶梯组、各模型的总 Token 除以实际扣费，计算器按余额逐段相乘相加。此决定取代 ADR-0001 至 0003 的 Redis 控制面、倍率中性拟合及候选发布方案。

## 范围和计算

- 仅组 ID 2/default、6/tier_1、7/tier_2、8/tier_3。同倍率的其他分组不纳入。
- 保留原有人民币、官方容量、Plus、阶梯边界计算。Token 不重复应用倍率，也不使用 total_cost 代替 actual_cost。
- 每天统计北京时间此前30个完整自然日，按请求 ID + API key ID 去重（与生产唯一索引一致，空请求 ID 按行保留）；总 Token 为输入、输出、缓存读取、缓存创建之和。
- 精确 `-proxy` 后缀合并。付费文本模型白名单包含现有六款、Astra 和独立的 gpt-5.6；免费、内部审核及图片模型不进入估算。
- 零扣费请求同时从 Token 和金额分母分子排除。
- 每组每模型至少10次、2个活跃日才更新；不足时保留该组模型上次值及原始统计日期。低于100次或7日标记样本有限。这些是保守的展示门槛，不是统计置信度声明。
- 2026-09-07 最新用户修订：有本档样本时仍直接使用本档总 Token / 实际扣费。仅缺档位的备用估算按倍率换算：中性备用系数 = sum(Token_M) / sum(各档实际扣费 / 各档倍率)，目标档产出 = 中性备用系数 / 目标倍率。明确标记借用和倍率换算；自定义倍率同样处理。完全无样本的模型不展示。例如0.40档每余额1.44M，缺失的0.32档估为1.80M。此近似使用分组倍率，并非逐请求精确还原计费。

## 数据流

后续展示范围修订：选择器仅保留 GPT-6 Astra、GPT-5.6 Terra、Sol、Luna；隐藏裸名 GPT-5.6、GPT-5.5、GPT-5.4 和 Mini。服务器历史聚合不删除，不擅自把裸名 GPT-5.6 并入其他模型。

服务器 Python 标准库脚本经 Docker psql 只读聚合，输出私有 CSV 和原子替换的 JSON 快照。systemd timer 每天北京时间03:15运行。公开域名上的 `/api/calc/usage` 使用独立 Bearer 密钥，只返回快照，无查询数据库操作。Nginx 拒绝私有文件目录的直接访问。

Vercel 服务端每小时缓存经过校验的数据，整页使用一小时 ISR 缓存，普通访问无需逐次运行页面函数。浏览器仅获得模型、各组产出比例、样本数量和日期，不获得密钥或实际扣费总额。首次构建读取失败阻止部署；运行时没有可用页面则显示错误页；已有缓存刷新失败继续使用缓存。数据超过两天未更新显示过期，日期按浏览器当前北京时间刷新；失败不会把旧值替换为零。两层缓存均按访问刷新，新快照可能需要两个小时缓存周期才显示。

## 验收

真实聚合批次能从接口进入计算器；手算跨档结果一致；请求无密钥返回401；私有路径不可访问；缺档位借用、零金额、空输入和失败保留旧值正确；页面标明估算及样本日期。黑框下方提供随输入变化的人民币/官方容量/Plus月额度说明。没有管理后台、新数据库或重新设计页面的范围。
